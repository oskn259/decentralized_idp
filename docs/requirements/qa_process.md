# QAプロセス

## ワークフロー

以下のすべてが成功することを確認。　

1. `npm run qa-gate` がpassすること
2. テストカバレッジが実装、要件に対して十分であること
3. 各要件について以下のいずれかであるかを確認

- 充足され、テスト済み
- 実装はされているがテストが不十分
- 未実装 / 本リポジトリでは実証不能
- 曖昧で、明確化が必要

4. 明示的な要件を超える疑わしい挙動やアンチパターンを確認
5. コードやプロジェクト全体の理解しやすさを確認

- コンテキストを持たない新規のエージェントを、以下についてそれぞれ実行する
  - 熟考タイプではなく高速応答モデルを起動してこのプロジェクトについて解説させる
    - その回答からして理解できていないところをQAフィードバックとして出力
  - code_philosophy.md と照らしてフィードバックを出力

7. ブロッカーや将来タスクを明確に報告する。テスト/ビルド gate がグリーンであることは要件のギャップを覆い隠さない。
