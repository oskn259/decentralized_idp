# ロゴ

記号は「しきい値の環」。3 つの弧のうち 2 つが揃えば環になる（t-of-n の署名）。1 つの弧だけ同じ色でわずかに薄い（86%）。3 つ揃っているように見えて 1 つは欠けてもよい、という事実を知っている人だけが読み取れる。記号は名前に依存しない。

| ファイル | 用途 |
|---|---|
| `mark.svg`, `mark-on-dark.svg` | 記号の原本（明背景用、暗背景用）。ここから他を書き出す |
| `logo-512.png` | 512×512、背景透過 |
| `favicon-16.png`, `favicon-32.png`, `apple-touch-icon.png`（180） | favicon |
| `banner-light.png`, `banner-dark.png` | 1920×1080、記号 + ワードマーク + 一文 |

ワードマークの書体は IBM Plex Sans 600。PNG は SVG を Chromium で描画して書き出したもので、名前や色を変えるときは SVG を直して書き出し直す。
